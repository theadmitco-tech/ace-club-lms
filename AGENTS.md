## Publication language and attribution

Repository-authored comments, documentation, handoff notes and commit messages must
use third-person wording and role-based attribution. Personal names, initials,
personal email addresses and usernames in local paths must be excluded from new
published content. New commits must use neutral project attribution rather than
personal author or committer metadata. Secrets and private session data must remain
outside version control.

Each push requires a review of changed text, generated PDF text and metadata,
screenshots, archived patches and commit attribution. Quoted interface labels and
technical identifiers remain exact when needed for truthful test evidence; authored
explanations use third-person language. Redacted or paraphrased source material must
be labeled accurately, with original source hashes distinguished from edited copies.
Historical Git records and applied migrations must not be rewritten as routine
wording cleanup. Production changes and PR readiness remain separately controlled.
