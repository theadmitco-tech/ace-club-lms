# Admin Preview review

The [Admin Preview](https://ace-club-ba60p2yk5-theadmitco-techs-projects.vercel.app/admin) requires Vercel access and an active staging Admin account. Student accounts continue to use the Student portal.

1. **Home:** the dashboard shows saved resource drafts, upcoming published classes and links to common tasks.
2. **Course content:** a published course opens its session outline. Each session groups pre-class readings, recordings, post-class readings and worksheets in order.
3. **Resource editing:** an Edit action opens one resource. Saving preserves a private draft; Review changes lists every affected course and session before Publish update becomes available.
4. **Student preview:** the separate tab uses the actual Student renderer. The preview does not write learning progress or feedback.
5. **Batches:** an existing batch opens Course & schedule and Review & publish as separate tasks. The calendar applies a date only after confirmation. Enrollment, live registration and private meeting controls remain contextual links.
6. **Students:** name search opens purchase expiry, enrollment and registration details. These records describe distinct access conditions; enrollment does not renew a purchase.
7. **More tools:** course templates, shared imports, pricing, account management and existing LMS tools remain available without occupying the primary navigation.

Production is unchanged. Payment-provider activation remains separate. The Preview contains real staging records; publication and enrollment confirmations perform actual staging actions.
