# Session ordering within the outline

Reorder now operates inside the existing left-hand session outline. The separate right-hand reorder view has been removed. Session titles remain selectable, and the corresponding published resources remain visible on the right while the order is edited. The selected session is tracked by its stable key, independently of its draft position.

Drag handles, move buttons, keyboard shortcuts, undo, save and publication links remain within the outline. The complete session list is shown during reordering so filtered-out sessions cannot be silently overlooked. The saved draft list remains visible until the editor closes. Existing request identities, conflict guards and explicit publication behavior are unchanged.
