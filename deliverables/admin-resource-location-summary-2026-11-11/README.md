# Compact resource locations

The resource editor replaces the expanded “Where this appears” section with a compact course, session and resource-stage summary. Shared resources display the additional location count. The Change control opens placement settings in an accessible modal only when needed.

Location edits remain local until Apply locations is selected. Cancel, Close and Escape preserve the original targets, ordering and replacement identity. Keyboard focus returns to the Change control. Search Enter cannot submit the underlying resource form. The redundant single-resource ordering list is omitted. Final publication review still presents affected current and previous locations before confirmation.

Validation covers 31 isolated browser journeys, including compact layout, cancellation, shared destinations, ordering, keyboard behavior, mobile overflow and focused automated accessibility checks. ESLint and an isolated webpack build including TypeScript passed. Source hashes identify the tested files. The build excludes unrelated local Student landing edits.

Browser evidence uses synthetic records and substituted Server Actions; it does not establish new hosted or database acceptance. The two synthetic screenshots were visually inspected and contain no embedded text or EXIF metadata. No PDFs or archived patches were generated. Production, database records, applied migrations and PR readiness remain unchanged. Preview publication awaits the branch push.
