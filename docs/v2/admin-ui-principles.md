# Admin interaction principles

Every Admin workflow that adds an item, selection or association must provide a discoverable way to remove or reverse it. Selected checkboxes remain interactive. Adding and removing an association use the same control wherever practical; removal is not hidden in unrelated settings.

Removal of the final required association must offer a clear alternative, such as an explicit resource-removal review. An unexplained disabled action is insufficient. Published-content removal retains the existing review and confirmation boundary; Cancel preserves the original state.

Routine choices remain visible. Advanced placement and ordering settings use progressive disclosure. Interfaces preserve entered values and existing resource metadata when a selection is removed and restored during an editing session.
